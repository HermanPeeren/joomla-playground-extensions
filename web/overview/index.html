    Joomla Component Builder fork

    Joomla 6.2 with Joomla Component Builder (JCB) and its plugins. It opens on JCB's dashboard: under Compiler, compile the Demo J6 component, then install it on the same site or download its zip. Starts in a few seconds from a prebuilt copy; add &fresh=1 to install JCB in your browser instead.

    JCB's own maintainer, Llewellyn van der Merwe, has a playground for it too: the JoomEngine Playground. JCB is its default, on Joomla 6 or 5. It runs a real MariaDB database compiled to WebAssembly instead of SQLite, on a 64-bit PHP, and adds JoomEngine Code, a code editor in the browser (VS Code's editor, with AI-assisted changes and PHP debugging), and Adminer for the database.

    An AI assistant in the playground fork

    An AI assistant on your computer (Claude Code, Claude Desktop, Codex, Gemini CLI or another MCP client) can work on the site in your playground tab: read and write its files, run PHP and Joomla's console, and show you the result. It needs a small MCP server on your computer, so there is no demo link: the assistant gives you the link, and the page asks you before it connects.

    How to set it up

    Test a pull request of Joomla

    The site opens without the patch. Apply patch in the toolbar applies it and shows the same page again, now with the changes; Revert patch takes them out, so before and after are one click apart. The playground starts the Joomla version of the pull request's branch.

    As a link: …/joomla-playground/?pr=48831, with &url= for the page. Changes to JavaScript or CSS are not built, so only PHP, template, language and XML changes show. See the open pull requests.

    Guided tours of the Joomla User Guide

    Tutorials of the Joomla User Guide as guided tours: each link opens a playground in the language of the tour, and the tour shows the way step by step.

      All tours and languages in one list: the list of tours.

      Make your own link

      Parameters set up a new playground; combine them with &.

      • A site in Dutch ?language=nl-NL
      • PHP 8.5 ?php=8.5
      • Open the front end ?url=/index.php
      • Start logged out ?login=no
      • Install an extension ?extension=<zip URL>
      • Your own blueprint ?blueprint-url=<JSON URL>

      A blueprint is a small JSON file with the steps to set up a site: install extensions, sample data, languages, articles, settings. See setting up a playground with a link.

      Everything runs in your browser: PHP is compiled to WebAssembly, and the site and its database live in the tab. Nothing is sent to a server. Use a recent Chrome, Edge or other Chromium browser. Source and documentation on GitHub.
